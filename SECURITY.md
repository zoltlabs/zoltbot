# Security

Please don't report vulnerabilities in public issues. Report them privately through [GitHub security advisories](https://github.com/zoltlabs/zoltbot/security/advisories/new).

Include the affected version or commit, steps to reproduce, and the impact. We'll acknowledge your report, keep you updated, and credit you when a fix ships, unless you'd rather stay anonymous.

Security fixes go to the latest release and `main`. In scope: the desktop app, the daemon, the iPhone app, and the client code for Zoltbot's hosted services. Vulnerabilities in third-party agent CLIs should go to their maintainers.
